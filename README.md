# Preview Pro 
; ---------------------------------------------------------------------------------------------------------------

First attempt at improving Preview app for Mac OS for better multitasking and better cohesion, will be updated with time. 

Run these commands in terminal to get it working.

1: First install Node.js through :  brew install node 

2:  unzip PreviewPro.zip && cd PreviewPro

3:  npm install

4:  npm run dist

Application can then be found under dist/mac-arm64/Preview Pro.app
Move to Application Folder
